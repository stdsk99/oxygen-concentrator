# Oxygen Concentrator Repair Trainer

สื่อฝึกซ่อมและบำรุงรักษาเครื่องผลิตออกซิเจน (oxygen concentrator) แบบ interactive สำหรับช่างเครื่องมือแพทย์
เครื่องในแอปเป็นเครื่องจำลองขนาด 5 L/min แบบ PSA รุ่นที่มีเซนเซอร์ O₂ ในตัว ค่าตัวเลขอ้างอิงจากคู่มือซ่อมของเครื่องประเภทเดียวกัน

## เนื้อหา

1. หลักการทำงาน – ภาพรวม 4 ระบบ (แผนผังแตะได้) เส้นทางอากาศทีละจุด และกราฟวงจรแรงดันสองถังพร้อม P.E. valve
2. การใช้งานสำหรับช่าง – แผงหน้าเครื่องจำลอง เร่งเวลาดูไฟสถานะ O₂ และตารางใช้งานผิดหรือเครื่องเสีย
3. ตรวจรับเครื่อง – ขั้นตอน เกณฑ์ และฝึกตัดสิน 5 เครื่อง
4. PM ตามแผน – รอบ PM เครื่องคำนวณรอบ วิธีทำแต่ละรายการ และฝึกเรียงขั้นตอน
5. วิเคราะห์อาการเสีย – ถอดรหัสไฟบนบอร์ด อาการที่ไม่มีรหัส และค่าอ้างอิง
- ด่านความปลอดภัย – ต้องถูกครบ 5 ข้อก่อนเข้าโมดูล 6
6. ถอดเปลี่ยนชิ้นส่วน – แตะชิ้นส่วนบนแผนผังดูขั้นตอน ข้อควรระวัง และการทดสอบหลังเปลี่ยน
7. ทดสอบหลังซ่อม – autotune จำลอง ทดสอบรั่ว เกจที่ช่องวัดแรงดัน และตารางทดสอบ alarm
8. โจทย์ซ่อมจำลอง – 10 เคส โหมดเรียนรู้และโหมดสอบ

เรียนตามลำดับ: โมดูล 1 → 2 → 3 → 4 → 5 → ด่านความปลอดภัย → 6 → 7 → 8 ขั้นถัดไปเปิดเมื่อผ่านขั้นก่อนหน้า
โมดูล 1–7 มีแบบทดสอบท้ายบท สุ่ม 5 ข้อ ต้องถูกอย่างน้อย 4 ข้อ (80%) ทำใหม่ได้ไม่จำกัด

## เกณฑ์ผ่าน (ใบรับรอง)

ด่านความปลอดภัย 5/5 · ผ่านท้ายบทครบ 7 โมดูล (โมดูลละ ≥ 80%) · โหมดสอบครบ 10 เคส · คะแนนรวม ≥ 80% (เฉลี่ยท้ายบท 7 โมดูลกับเฉลี่ยโหมดสอบ)
ตั้งค่าที่ `data/config.js` และต้องตรงกับ `APPS.o2.crit` ใน `apps-script/Code.gs`

## โครงสร้างไฟล์

```
index.html          โครงหน้าเว็บ
css/style.css       หน้าตาร่วมกับแอปอื่นในศูนย์การเรียนรู้
css/o2.css          หน้าตาเฉพาะแอปนี้
data/config.js      ตั้งค่า URL ส่งคะแนน เกณฑ์ผ่าน และใบรับรอง
data/lessons.js     ด่านความปลอดภัย เนื้อหาโมดูล 1–7 และคลังข้อสอบท้ายบท
data/parts.js       ชิ้นส่วน ระบบ และเส้นทางอากาศ
data/trouble.js     รหัสไฟบนบอร์ดและอาการที่ไม่มีรหัส
data/cases.js       รายการตรวจ การวินิจฉัย งานซ่อม การทดสอบ และ 10 เคสของโมดูล 8
js/app.js           เมนู หน้าโมดูล แบบทดสอบ ด่านความปลอดภัย และเกณฑ์ผ่าน
js/diagram.js       แผนผังภายในเครื่อง (SVG)
js/widgets.js       สื่อโต้ตอบในบทเรียน
js/repair.js        โมดูล 8
js/score.js, auth.js, cert.js   ระบบบัญชี คะแนน และใบรับรอง (ชุดเดียวกับแอปอื่น)
apps-script/        Code.gs ที่เพิ่มแอป o2 แล้ว
```

## ก่อนเปิดใช้

1. อัปเดต Apps Script ด้วย `apps-script/Code.gs` แล้ว Deploy เป็น New version (ดู `apps-script/README.md`)
2. เปิด GitHub Pages: Settings → Pages → Deploy from a branch, `main`, `/ (root)` → `https://stdsk99.github.io/oxygen-concentrator/`
3. เพิ่มวิชาในเว็บหลัก (branch `add-oxygen-concentrator` ของ stdsk99/medtechcenter)

ผู้สอนดูเนื้อหาได้โดยไม่ต้องเข้าสู่ระบบที่ `…/oxygen-concentrator/?preview` (คะแนนไม่ส่งเข้าระบบ)

## หมายเหตุ

- เนื้อหาและภาพจัดทำขึ้นใหม่เพื่อการศึกษา ไม่ได้คัดลอกภาพหรือตารางจากคู่มือ และไม่ระบุยี่ห้อหรือรุ่น
- ค่าตัวเลขเป็นค่าของเครื่องจำลอง การซ่อมเครื่องจริงให้ใช้ค่าจาก service manual ของรุ่นนั้น
